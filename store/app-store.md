## Что сделать, когда появится аккаунт Apple Developer
1. Оплатить Apple Developer Program (99 $ в год) на developer.apple.com.
2. App Store Connect → Apps → «+» → New App: платформа iOS, имя Fac Modo, основной язык русский, Bundle ID `io.github.azazello2508.facmodo`, SKU `facmodo-ios`.
   (Если Bundle ID нет в списке — developer.apple.com → Identifiers → «+» → App IDs → тот же ID.)
3. Users and Access → Integrations → App Store Connect API → создать ключ с ролью **Admin**, скачать файл `AuthKey_XXXX.p8` (скачивается один раз!), записать Key ID и Issuer ID.
4. developer.apple.com → Membership → записать Team ID.
5. GitHub → репозиторий Fac-modo → Settings → Secrets and variables → Actions → New repository secret:
   `APPLE_TEAM_ID`, `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (весь текст файла .p8).
6. GitHub → Actions → «Отправка в App Store» → Run workflow. Через 10–30 минут сборка появится в App Store Connect → TestFlight.
7. Поставить приложение через TestFlight на свой iPhone и проверить.
8. Заполнить карточку тексты/скриншоты/конфиденциальность/рейтинг из этого файла → выбрать сборку → Submit for Review.
