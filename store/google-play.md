## Сборка для Google Play
- Workflow «Сборка для Android» кладёт в выпуск `android-apk` два файла: `FacModo.apk` (установка по ссылке, как раньше) и **`FacModo.aab`** (его загружать в Play Console):
  https://github.com/Azazello2508/Fac-modo/releases/download/android-apk/FacModo.aab
- AAB подписан тем же ключом (секреты `ANDROID_KEYSTORE` / `ANDROID_KEY_PASS`, копия — `Клод\Костя\android-key\`).
- Точные будильники (`SCHEDULE_EXACT_ALARM`) из манифеста убраны: напоминания раз в день работают без них (сработают с небольшим сдвигом), Play не придётся объяснять это разрешение.
- Остальные разрешения: интернет, камера (QR и фото), вибрация, уведомления, возврат напоминаний после перезагрузки телефона; запись в память — только Android 9–10.

## Data safety (Безопасность данных)
Отвечать так:
- «Собирает ли приложение или передаёт данные третьим лицам?» → **Нет, не собирает и не передаёт.**
  Всё хранится только на телефоне. Единственное исключение — режим «вдвоём по коду комнаты» в «Танчиках» и «Самолётиках» (сервер tanchiki-server.pinkovskyi2508.workers.dev, Cloudflare): передаётся только состояние игры, не связанное с личностью, ничего не сохраняется. Это временная передача в реальном времени, по правилам Google она не считается «сбором». IP-адрес сервер видит как любой сайт.
  Если консоль всё же потребует указать — отметить как временную обработку («ephemeral»), без хранения и без передачи третьим лицам.
- Шифрование при передаче: **Да** (https/wss).
- Удаление данных: данные только на устройстве — кнопка «Сбросить весь прогресс» или удаление приложения. Аккаунтов нет.
- Ссылка на политику конфиденциальности — см. таблицу выше.

## Декларации (App content)
- **Реклама:** нет.
- **Доступ к приложению:** всё доступно без входа, данных для проверяющих не нужно.
- **Целевая аудитория:** 18+ (взрослые моряки). Не детское приложение, не «для семей».
- **Health apps (здоровье):** приложение **не медицинское**. Советы по сну, питанию и тренировкам («Зал», сон, дыхание) общие, это не диагностика и не лечение, подключения к медприборам и датчикам нет. В декларации не отмечать медицинские функции; в описании есть оговорка «не медицинские».
- **Финансовые функции:** нет (учёт расходов — просто записи на телефоне).
- **Новости, COVID-19, государственное приложение:** нет.
- **Права на фильмы и книги:** только книги и фильмы без авторских прав (Gutenberg, Wikisource, Internet Archive); остальное — ссылки на поиск JustWatch.
- **Разрешения:** камера (QR и фото), уведомления (Android 13+). Точные будильники и доступ ко всем файлам не используются.

## Анкета возрастного рейтинга (IARC)
Категория — «Утилита / справочник» (не игра). Ответы как в `store/app-store.md`:
- Мультяшное насилие (аркадные «Танчики», «Самолётики», «Морской бой») → **редко/мягкое**
- Реалистичное насилие, сексуальный контент, ненормативная лексика, наркотики, азартные игры, страх → **нет**
- Общение между пользователями и пользовательский контент → **нет** (игра по сети — без чата, только ходы)
- Передача местоположения → **нет**; покупки внутри приложения → **нет**
- Ожидаемый рейтинг: примерно 3+ / PEGI 3–7 (итог покажет сама анкета).

## Закрытое тестирование (новый личный аккаунт)
Новый личный аккаунт разработчика обязан перед выпуском провести **закрытое тестирование: минимум 12 тестировщиков, 14 дней подряд**, затем подать заявку на «Production access».
План: закрытый трек → список тестировщиков (Google-группа или e-mail’ы) → 12+ человек принимают приглашение и ставят приложение из Play → 14 дней не удаляют → «Apply for production». Тестировщиков можно набрать среди коллег-моряков.

## Что сделать пользователю — по шагам
1. Завести отдельную почту для приложения → вписать в `privacy.html` и `support.html` (заменить комментарии `<!-- EMAIL: вписать почту -->` видимой строкой) и в Play Console.
2. Создать аккаунт разработчика на play.google.com/console (разово 25 $), подтвердить личность.
3. Create app: имя Fac Modo, язык по умолчанию русский, «Приложение», «Бесплатное».
4. Дождаться сборки Android на GitHub и скачать `FacModo.aab` (ссылка выше).
5. Testing → Closed testing → Create release: включить **Play App Signing** и загрузить `FacModo.aab`.
   Чтобы поставленные из APK копии потом обновлялись из Play, при первой загрузке выбрать «использовать существующий ключ подписи» и загрузить ключ из `Клод\Костя\android-key\` (консоль подскажет, как его экспортировать). Если выбрать новый ключ Google — установленные из APK придётся поставить заново (сначала сделать резервную копию данных в приложении).
6. Заполнить карточку: тексты из этого файла, иконка, баннер, скриншоты, категория, e-mail, политика.
7. Заполнить App content: реклама, доступ, аудитория, Health apps, Data safety, рейтинг.
8. Набрать 12+ тестировщиков, разослать ссылку-приглашение, 14 дней ждать.
9. «Apply for production» → ответить на вопросы Google → отправить на проверку (обычно несколько дней).
10. Дальше обновления — новыми `.aab` (versionCode растёт сам). Самообновление веб-части внутри приложения остаётся только для исправлений и текстов.
