## Часть 1. Установка Claude Code на Windows (один раз)

Нужна подписка Claude (Pro или Max) — та же, что на claude.ai.

### Шаг 1. Поставить Git
1. Открой https://git-scm.com/download/win и скачай установщик (64-bit).
2. Запусти его и жми **Next** до конца, ничего не меняя.

Проверка: нажми **Win + R**, напиши `powershell`, нажми Enter. В синем окне напиши `git --version` и Enter.
Должно появиться что-то вроде `git version 2.xx`.

### Шаг 2. Поставить Claude Code
В том же окне PowerShell вставь эту строку и нажми Enter:

```powershell
irm https://claude.ai/install.ps1 | iex
```

Когда закончится, **закрой окно PowerShell и открой новое** (Win + R → `powershell`).

Проверка: напиши `claude --version` — должен показаться номер версии.

> Если окно пишет, что команда `claude` не найдена, перезагрузи компьютер и проверь ещё раз.
> Другой путь без командной строки: приложение **Claude для Windows** (claude.ai/download), вкладка **Code**.

### Шаг 3. Скачать код приложения в папку «Документы\Fac Modo»
В PowerShell по очереди (каждую строку + Enter):

```powershell
cd "$env:USERPROFILE\Documents\Fac Modo"
git clone https://github.com/Azazello2508/Fac-modo.git
cd Fac-modo
```

Теперь код лежит в `Документы\Fac Modo\Fac-modo`. Твои файлы (FacModo.ipa, резервные копии) рядом не пострадают.

### Шаг 4. Запустить Claude Code
Находясь в папке `Fac-modo`, напиши:

```powershell
claude
```

В первый раз откроется браузер — войди в свой аккаунт Claude. Потом Claude спросит, доверяешь ли ты папке — ответь **Yes**.
Claude сам прочитает `CLAUDE.md` с правилами проекта.

### Шаг 5. Вход в GitHub (чтобы Claude мог отправлять правки)
При первой отправке (`git push`) Windows сама откроет окно входа в GitHub — войди как **MDCCCLXIII**.
Ещё удобнее поставить GitHub CLI: https://cli.github.com/ → установить → в PowerShell `gh auth login` и выбрать
GitHub.com → HTTPS → Login with a web browser. Тогда Claude сможет сам создавать Pull Request.

### Каждый следующий раз
Win + R → `powershell` → 
```powershell
cd "$env:USERPROFILE\Documents\Fac Modo\Fac-modo"
claude
```

Полезные команды внутри Claude Code: `/help` — помощь, `/clear` — начать разговор заново, **Esc** — остановить Claude,
**Shift + Tab** — переключить режим (например, «сначала план, потом правки»).

## Часть 3. Где что лежит

| Что | Где |
|---|---|
| Код (главный источник) | https://github.com/Azazello2508/Fac-modo, всё приложение в `index.html` |
| Код у тебя на компьютере | `Документы\Fac Modo\Fac-modo` (после шага 3) |
| Сайт | https://azazello2508.github.io/Fac-modo/ |
| iPhone | https://github.com/Azazello2508/Fac-modo/releases/latest/download/FacModo.ipa (через Sideloadly, см. README) |
| Android | https://github.com/Azazello2508/Fac-modo/releases/download/android-apk/FacModo.apk |
| Правила для Claude | `CLAUDE.md` в репозитории |
| Адрес обновлений программы на ПК | `%APPDATA%\Fac Modo\update-url.txt` (сейчас `https://azazello2508.github.io/Fac-modo/`) |

Как приходят обновления: правка в `main` → GitHub сам публикует сайт и собирает ipa/apk → приложение на
телефоне и ПК само скачивает новую версию при следующем открытии с интернетом.

Отдельного репозитория `fac-modo-update` больше нет (удалён 23.10.2026), обновления снова идут из `Fac-modo`.

## Часть 7. Как Claude работать с Костей
- Костя — новичок: по-русски, просто, короткими шагами, после каждого шага «что сделано и как проверить».
- Windows + iPhone; удобнее всего ссылка на сайт.
- Не добавлять функции, которые он не просил.
- Крупное — в отдельной ветке через Pull Request; перед работой `git pull --rebase origin main`; никогда `git push --force` в `main`.
- Перед действием, которое нельзя отменить (удаление, отправка писем, публикация в App Store), спросить Костю.
