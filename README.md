# Fac Modo

Игровой помощник для моряков: миссии дня, знания, книги, игры (включая «Танчики»), путь на берег, дневник.

Открыть: https://azazello2508.github.io/fac-modo/

На iPhone: открыть ссылку в Safari → «Поделиться» → «На экран „Домой“». Приложение работает без интернета.

## Приложение для iPhone (без App Store)

После каждого обновления GitHub сам собирает файл приложения **FacModo.ipa**.
Последняя версия всегда лежит здесь: https://github.com/Azazello2508/Fac-modo/releases/latest/download/FacModo.ipa

Установка с компьютера на Windows (бесплатно, через свой Apple ID):

1. Установить **iTunes** и **iCloud** с сайта apple.com (не из Microsoft Store).
2. Установить **Sideloadly** с сайта sideloadly.io.
3. Подключить iPhone кабелем, на телефоне нажать «Доверять этому компьютеру».
4. В Sideloadly перетащить FacModo.ipa, ввести свой Apple ID, нажать **Start**.
5. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить, перезагрузить телефон.
6. На iPhone: Настройки → Основные → VPN и управление устройством → свой Apple ID → **Доверять**.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить тем же способом
(или включить в Sideloadly автообновление). Данные приложения при переустановке сохраняются.

## Приложение для Android

После каждого обновления GitHub сам собирает файл приложения **FacModo.apk**.
Последняя версия всегда лежит здесь: https://github.com/Azazello2508/Fac-modo/releases/download/android-apk/FacModo.apk

Установка (компьютер не нужен):

1. Открыть ссылку выше на телефоне в Chrome, скачать FacModo.apk.
2. Открыть скачанный файл. Телефон спросит, можно ли ставить приложения из этого источника — разрешить.
3. Нажать **Установить**.

Новые версии ставятся тем же способом поверх старой, данные сохраняются. Небольшие обновления приложение скачивает само, как на iPhone.
Резервная копия и таблицы сохраняются в папку «Документы → Fac Modo».
