# Fac Modo

**Fac Modo** («Делай как надо», лат.) — игровой помощник для моряков, который подходит и обычным людям.
Сделан моряком-электромехаником для своих: чтобы держать день в порядке в рейсе, учиться,
отдыхать и спокойно подготовить переход с моря на берег (IT, умный дом и другие профессии).

Открыть в браузере: https://azazello2508.github.io/Fac-modo/

Работает **без интернета** (на судне связи часто нет), на iPhone, Android и компьютере.
Языки: русский, английский, украинский. Сервера нет: все данные хранятся только на устройстве.

## Что умеет

- **Сегодня:** миссии дня с XP и уровнями, штрафы за пропуски, расписание, вахта и сон, цитата и идея дня.
- **Знания:** библиотека статей (электромеханика, пассажирские суда, оффшор, безопасность, финансы, психология…),
  мини-экзамен с повтором ошибок, тренажёр собеседования на английском, калькуляторы ЭТО, журнал ремонтов.
- **Досуг:** шахматы, шашки, нарды, дурак, деберц (с ботами, вдвоём и по сети), «Танчики», «Самолётики»,
  морской бой, судоку, 2048, книги и фильмы офлайн.
- **Берег:** дорожные карты по профессиям, план ухода с моря по месяцам, резюме, отклики.
- **Дневник, профиль, настройки:** настроение, рисунки, достижения, награды за уровни, темы, живое море,
  резервные копии и перенос данных на новый телефон.

## Как установить

### iPhone (без App Store)
После каждого обновления GitHub сам собирает файл **FacModo.ipa**:
https://github.com/Azazello2508/Fac-modo/releases/latest/download/FacModo.ipa

Установка с компьютера на Windows (бесплатно, через свой Apple ID):

1. Установить **iTunes** и **iCloud** с сайта apple.com (не из Microsoft Store).
2. Установить **Sideloadly** с сайта sideloadly.io.
3. Подключить iPhone кабелем, на телефоне нажать «Доверять этому компьютеру».
4. В Sideloadly перетащить FacModo.ipa, ввести свой Apple ID, нажать **Start**.
5. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить, перезагрузить телефон.
6. На iPhone: Настройки → Основные → VPN и управление устройством → свой Apple ID → **Доверять**.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переустановить тем же способом
(или включить в Sideloadly автообновление). Данные приложения при переустановке сохраняются.

Без установки: открыть ссылку на сайт в Safari → «Поделиться» → «На экран „Домой“».

### Android
После каждого обновления GitHub сам собирает **FacModo.apk**:
https://github.com/Azazello2508/Fac-modo/releases/download/android-apk/FacModo.apk

1. Открыть ссылку на телефоне в Chrome, скачать FacModo.apk.
2. Открыть скачанный файл, разрешить установку из этого источника.
3. Нажать **Установить**.

Новые версии ставятся поверх старой, данные сохраняются. Резервная копия и таблицы сохраняются в «Документы → Fac Modo».

## Как обновляется

1. Правка попадает в ветку `main` (сразу или через Pull Request).
2. GitHub сам публикует сайт и `version.json` (pages.yml), собирает `FacModo.ipa` (ios.yml) и `FacModo.apk` (android.yml).
3. Приложение на телефоне и компьютере видит новый номер сборки в `version.json`, скачивает новую версию
   и включает её при следующем открытии. Переустанавливать ничего не нужно.

Номер сборки (`__FM_BUILD__`) подставляется сам при сборке, вручную его не менять.

## Как запустить у себя (для разработки)

Нужны [Git](https://git-scm.com/download/win), [Python 3](https://www.python.org/downloads/) и [Node.js 22](https://nodejs.org/).

```bash
git clone https://github.com/Azazello2508/Fac-modo.git
cd Fac-modo
python -m http.server 8765
```

Открыть в браузере http://localhost:8765/ — это то же приложение, что на сайте.

Проверки (их же GitHub запускает на каждый Pull Request):

```bash
npm install --no-save playwright@1.63.0 axe-core@4.10.2
npx playwright install chromium
node tests/e2e.js                          # приложение, мобильный экран, игры по сети, доступность
node tests/full.js static xss net upload pin   # быстрая часть большого теста
```

## Что где лежит

| Путь | Что это |
|---|---|
| `index.html` | **Всё приложение в одном файле** (вёрстка, стили, код, тексты, встроенные игры) |
| `games/*.html` | Исходники настольных игр; встраиваются в `index.html` командой `python3 tools/embed_tanchiki.py games/<игра>.html <блок>` |
| `tools/` | Скрипты: встраивание игр, переводы (`i18n_*`), библиотека статей, сборка iOS/Android, нагрузочный тест |
| `tests/` | Автотесты: `e2e.js` и большой тест `full.js` (части в `tests/full/`) |
| `.github/workflows/` | Автоматика GitHub: сайт, сборки iPhone/Android, тесты, ежечасное обновление игр |
| `sw.js`, `manifest.webmanifest` | Работа сайта без интернета и установка «на экран Домой» |
| `privacy.html`, `support.html`, `store/` | Политика конфиденциальности, поддержка, тексты для App Store |
| `CLAUDE.md` | Правила работы для Claude Code (читать перед любыми правками) |
| `HANDOFF.md` | Как продолжить работу в Claude Code: установка, первые шаги, открытые задачи |
